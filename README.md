# estudos-copilot

## Descrição

Este repositório é dedicado aos **estudos do GitHub Copilot**, seguindo os módulos de treinamento disponibilizados pela Microsoft.

## Objetivo

Aprender e praticar as funcionalidades do GitHub Copilot através dos recursos educacionais oficiais da Microsoft.

## Recursos de Aprendizado

- [Microsoft Learn - Módulos sobre Copilot](https://learn.microsoft.com/pt-br/training/browse/?resource_type=module&terms=copilot)

## Conteúdo

Este repositório contém:
- Exemplos de código
- Exercícios práticos
- Anotações de aprendizado
- Projetos de estudo

## Como Usar

1. Clone este repositório
2. Explore os exemplos e exercícios
3. Siga os módulos de treinamento da Microsoft Learn
4. Pratique com o GitHub Copilot
